# KRAMM - notatka po rozmowie

Aplikacja dla agentek KRAMM. Po rozmowie telefonicznej pyta głosem o numer, osobę, sprawę oraz alert lub zadanie, a potem zapisuje wpis do arkusza Google agentki.

- `index.html` - aplikacja (GitHub Pages)
- `Code.gs` - skrypt Apps Script do arkusza agentki (instrukcja w nagłówku pliku)
